# Портфолио веб-разработчика

Готовый статический сайт на HTML, CSS и JavaScript. Для просмотра и публикации не требуется устанавливать зависимости.

## 1. Откройте сайт на компьютере

Распакуйте архив и дважды щёлкните по файлу `index.html`. В блоке «Избранные проекты» есть два сайта и ссылка на бота в Telegram.

- **Ремонт техники.** Выберите тип техники и время, опишите вымышленную поломку. Нажмите «Подготовить заявку», откройте бота и отправьте подготовленное сообщение. Если Telegram не подставил текст, его можно скопировать под формой. Когда бот передаст заявку владельцу, он подтвердит доставку в чате.
- **Салон красоты.** Выберите услугу, одну из семи ближайших дат и время. Форма покажет тестовую запись.
- **Telegram-бот.** Нажмите «Попробовать в Telegram», затем «Старт». Бот показывает услуги и цены и передаёт заявку владельцу, пока запущен.

Все три проекта сделаны для портфолио. Запись в салон работает в браузере. Заявка на ремонт передаётся только после отправки сообщения в Telegram. Используйте вымышленные данные.

## 2. Добавьте свои контакты

В `assets/contacts.js` указаны имя, Telegram и публичная почта. Чтобы изменить контакты, отредактируйте поля `telegram` и `email`. Оставьте `""` в поле контакта, которое хотите скрыть. Фото находится в `assets/daniil-samokhov.webp`, путь к нему указан на главной странице.

Сохраните файл и обновите страницу. Имя появится в шапке и в разделе «Обо мне». В разделе «Контакты» появятся кнопки только для заполненных каналов. Ссылка на почту открывает новое письмо в почтовом приложении. Нажмите каждую кнопку и проверьте, что открывается ваш профиль или письмо адресовано вам.

Текст разделов и ориентир стоимости редактируются в `index.html`. В публичный репозиторий добавляйте только те контактные данные, которые готовы разместить на сайте.

## 3. Опубликуйте бесплатно на GitHub Pages

1. Войдите в GitHub и создайте репозиторий с именем `portfolio`. Выберите **Public** и включите **Add README**. Нажмите **Create repository**.
2. На вкладке **Code** выберите **Add file → Upload files**. Перетащите содержимое распакованной папки. В корне репозитория должны лежать `index.html`, папки `assets` и `demos`, а также `README.md`. Саму папку `portfolio` целиком не перетаскивайте. Нажмите **Commit changes** и сохраните в ветку `main`.
3. Если скрытый файл `.nojekyll` не попал в загрузку, в корне репозитория выберите **Add file → Create new file**, введите имя `.nojekyll`, добавьте одну строку `Static site` и нажмите **Commit changes**. GitHub Pages использует наличие этого файла для публикации без обработки Jekyll.
4. Откройте **Settings → Pages**. В **Build and deployment** выберите **Deploy from a branch**, затем ветку **main** и папку **/ (root)**. Нажмите **Save**.
5. После публикации откройте **Settings → Pages → Visit site**. Для репозитория `portfolio` адрес будет выглядеть как `https://ВАШ-ЛОГИН.github.io/portfolio/`. GitHub сообщает, что обновление может занять до 10 минут. Статус публикации также виден во вкладке **Actions**.
6. Откройте опубликованный адрес на телефоне, проверьте контакты, три демо и возврат к проектам. В отклике заказчику можно дать ссылку на портфолио или непосредственно на страницу демо.

[Создание сайта на GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) · [Загрузка файлов через браузер](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)

## Как работает бот в Telegram

Ссылка на бота находится в карточке проекта в `index.html`, а форма ремонта открывает его с подготовленным сообщением. Для приёма заявок с сайта запустите обновлённый `bot.py` и укажите ID чата владельца. Для круглосуточной работы понадобится хостинг, который поддерживает постоянно работающие Python-процессы. [Документация Telegram Bot API](https://core.telegram.org/bots/api#getupdates).

| `assets/style.css`, `assets/demo.css` | Вёрстка, цвета и мобильные стили |
| `assets/site.js` | Отображение имени и ссылок на контакты |
| `assets/forms.js`, `assets/bot.js` | Сценарии форм и диалога |
| `demos/` | Страницы трёх проектов |
